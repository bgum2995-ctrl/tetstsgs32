# Трекер состояния

Сайт для ежедневного трека: утром 6 слайдеров (1 — хорошо, 5 — плохо), вечером 4 вопроса да/нет и заметка.
Данные Дарьи и Данила пишутся каждому в свою Google Таблицу, одна строка на день.
Повторная отправка за тот же день перезаписывает значения.

Как устроено: сайт (`index.html`, `style.css`, `app.js`) отправляет ответы в Netlify Function
(`netlify/functions/save.mjs`). Функция проверяет PIN и записывает строку в таблицу через
сервисный аккаунт Google. Все PIN-коды и ключи хранятся в настройках Netlify, а не в коде.

## Настройка (один раз)

### 1. Сервисный аккаунт Google (около 10 минут, бесплатно)

Это «робот», которому вы дадите право писать в ваши таблицы. Сервер не нужен, карта не нужна.

1. Откройте https://console.cloud.google.com и войдите своим Google-аккаунтом.
2. Сверху нажмите на выбор проекта → **Новый проект** → назовите, например, `tracker` → **Создать**.
3. Откройте https://console.cloud.google.com/apis/library/sheets.googleapis.com, проверьте, что выбран проект `tracker`, и нажмите **Включить** (Enable).
4. Откройте https://console.cloud.google.com/iam-admin/serviceaccounts → **Создать сервисный аккаунт**.
   Имя любое, например `tracker-bot`. Нажмите **Готово**, роли выдавать не нужно.
5. Нажмите на созданный аккаунт → вкладка **Ключи** → **Добавить ключ** → **Создать новый ключ** → **JSON**.
   Скачается файл. Никому его не пересылайте и не загружайте в GitHub.
6. Скопируйте почту аккаунта, она выглядит так: `tracker-bot@tracker-12345.iam.gserviceaccount.com`.

> Если при создании ключа Google пишет, что ключи запрещены политикой организации,
> значит вы вошли рабочим аккаунтом. Используйте обычный личный Gmail.

### 2. Таблицы

1. Создайте две Google Таблицы: одну для Дарьи, одну для Данила (можно у каждого на своём Диске).
2. В каждой нажмите **Настройки доступа** и добавьте почту сервисного аккаунта из шага 1.6 с правом **Редактор**.
3. Скопируйте ID каждой таблицы из адреса: в `https://docs.google.com/spreadsheets/d/`**`1AbC...xyz`**`/edit` ID — это выделенная часть.

Шапку столбцов сайт создаст сам при первой отправке. Данные пишутся на первый лист.

### 3. Переменные в Netlify

В Netlify откройте сайт → **Site configuration** → **Environment variables** → **Add a variable**
и добавьте шесть переменных:

| Имя | Значение |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | почта сервисного аккаунта (шаг 1.6) |
| `GOOGLE_PRIVATE_KEY` | из скачанного JSON-файла: значение поля `private_key` целиком, от `-----BEGIN PRIVATE KEY-----` до `-----END PRIVATE KEY-----\n`, без кавычек |
| `DARYA_PIN` | PIN Дарьи |
| `DARYA_SHEET_ID` | ID таблицы Дарьи |
| `DANIL_PIN` | PIN Данила |
| `DANIL_SHEET_ID` | ID таблицы Данила |

После добавления переменных откройте **Deploys** → **Trigger deploy** → **Deploy site**, чтобы они подхватились.

### 4. Подключение репозитория к Netlify

**Add new site** → **Import an existing project** → **GitHub** → выберите этот репозиторий.
Настройки сборки оставьте пустыми, всё нужное уже есть в `netlify.toml`. После этого каждый `git push` обновляет сайт.

## Шрифт Nauryz Red Keds

Его нет в Google Fonts, поэтому файл нужно положить в папку `fonts/` под именем
`NauryzRedKeds.woff2` или `NauryzRedKeds.ttf`. Пока файла нет, заголовки показываются шрифтом Comfortaa.
