# Штиль

Дневник состояния. Сайт для ежедневного трека: утром 6 слайдеров (1 — плохо, 5 — хорошо, у каждого деления свой текст), вечером 4 вопроса «Да / Частично / Нет» и заметка.
Во вкладке «Статистика» каждый видит только свои данные: среднее за неделю, календарь месяца, графики за 7 или 30 дней, ответы вечера и заметки.
У Дарьи и Данила свои PIN-коды и свои данные. За день хранится одна запись, повторная отправка её перезаписывает.

Как устроено: сайт (`index.html`, `style.css`, `app.js`) отправляет ответы в Netlify Functions
(`netlify/functions/`). Функции проверяют PIN и хранят данные в Netlify Blobs, это встроенное хранилище Netlify.
Google и другие сервисы не нужны.

Кнопка «Скачать таблицу» выгружает все записи файлом CSV. Он открывается в Excel двойным щелчком,
а в Google Таблицах через «Файл → Импорт».

## Настройка (один раз)

1. В Netlify: **Add new project** → **Import an existing project** → **GitHub** → этот репозиторий.
   Настройки сборки оставьте пустыми, всё нужное уже есть в `netlify.toml`.
2. **Project configuration** → **Environment variables** → добавьте две переменные:

   | Имя | Значение |
   |---|---|
   | `DARYA_PIN` | PIN Дарьи |
   | `DANIL_PIN` | PIN Данила |

3. После добавления или изменения переменных нажмите **Deploys** → **Trigger deploy** → **Deploy project**.
   Netlify подхватывает переменные только при новой сборке.

После этого каждый `git push` обновляет сайт автоматически.

Шкала слайдеров везде одна: 1 — плохо, 5 — хорошо.
Записи до 27.10.2026 сохранены по старой шкале (1 — хорошо) и переворачиваются при чтении, поэтому в статистике и выгрузке всё в одной шкале.
